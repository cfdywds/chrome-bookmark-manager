User Guide & Shortcuts

Primary Entries
  • Overview —

    Quick statistics, health audits, tag cloud, and one-click duplicate/empty cleanup tools.

  • Organize —

    Full hierarchical folder tree and tag groups with drag-to-reorder and bulk editing.

  • Hidden —

    Private bookmark vault isolated from browser omnibox, search, and new tab display.

General Tips
  • Select any bookmark row to reveal the bottom bulk-action bar (Move, Tag, Delete).
  • Click bookmark title to open directly; hold Ctrl / ⌘ to open in background tab.
  • Drag row handle to reorder, or drop into another folder to merge hierarchy.
  • All deletions are safely routed to Recycle Bin (retained for 30 days before purge).
  • Click the four-pointed sparkle icon on any row to generate smart tags using your configured LLM.
  • Duplicate bookmarks are highlighted with alert indicators for safe one-click merge.
  • Click folder header chip to filter view exclusively to items in that specific sub-tree.
  • Export a complete JSON backup at any time from Settings → Danger Zone.

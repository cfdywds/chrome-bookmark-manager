    书签备份 / 恢复

    导出全部书签为 V4 JSON 文件；恢复时默认合并相同网址的书签与标签，也可以选择保留副本。恢复会写入书签和扩展标签数据，请先确认备份文件来源。

    清空回收站

    永久删除当前回收站中的所有记录，待恢复书签将无法找回。侧边栏仍可查看和恢复单条记录。

    删除当前选中的 AI 配置

    删除后该配置的接口地址、API Key 与模型名一并移除且无法恢复（其余配置不受影响）。删除前请先在「AI 分类」分组中确认当前选中的配置；标签原生同步只是停止读写、已有数据保留，不属于危险操作。

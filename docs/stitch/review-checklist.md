# Stitch 产出评审清单

对每个变体逐项过。**A 组是一票否决**——任何一项不过，该变体直接废弃，不必再评 B 组。

---

## A. 硬性拒绝项（一票否决）

| # | 检查项 | 怎么查 |
|---|---|---|
| A1 | 出现白名单外的颜色 | 对着 `.stitch/DESIGN.md` 的 Colors 表逐个比对。重点抓紫色系（`#8B5CF6` / `#A855F7` 一类）、Material 蓝 `#4285F4` |
| A2 | 出现白名单外的圆角 | 目测异常大的圆角（22px 一类）；在代码视图里搜 `border-radius` 逐个核对，只允许 7 / 10 / 14 / 18 / 999 |
| A3 | 出现 Tailwind 类名或内联样式 | 代码视图搜 `class="flex`、`class="p-`、`style="` |
| A4 | 输出了中文或试图渲染中文字形 | 生成稿里所有文案都应是英文占位 |
| A5 | 出现营销区块 | hero 大图、定价卡、订阅引导、带图表的看板——本项目没有这些模块 |
| A6 | 360px 下横向溢出 | 把预览视口拖到 360px 宽，看是否需要横向滚动 |
| A7 | 把书签行／列表行做成了卡片 | 上一轮已明确记录这个退化风险：列表视图套卡片边框会退化成单列卡片网格 |
| A8 | 深色模式只是机械反色 | 检查 `bg` / `panel` / `sub` 三档表面在深色下是否仍可辨——糊成一片即否决 |
| A9 | 缺少状态 | 列表型界面没有空状态 / 加载态 / 错误态中任意一项 |

> A6 是最容易漏但后果最重的一条。Chrome 侧边栏内宽下限约 320–360px，横向溢出的设计在这个容器里直接不可用。

---

## B. 评分维度（每项 1–5 分）

对通过 A 组的变体打分。

| # | 维度 | 5 分长什么样 | 1 分长什么样 |
|---|---|---|---|
| B1 | **信息密度** | 360×720 首屏内能完成主任务（找到并打开书签、发起批量操作） | 首屏被 KPI 卡和留白占满，要滚动才能看到书签 |
| B2 | **视觉层级** | 标题 / 次级信息 / chip 三级一眼可分，眼睛能沿标题列竖向扫读 | 所有元素同权重，糊成一片 |
| B3 | **双主题质量** | 深色下三档表面成立，卡片与背景边界清晰 | 深色下卡片与背景同色，靠边框勉强分辨 |
| B4 | **交互可发现性** | 拖拽把手、行操作、批量选择在需要时自然出现 | 拖拽完全看不出可以做，操作按钮永远藏着 |
| B5 | **可落地性** | 能在现有类名体系里实现，不需要新增顶层组件 | 需要重写 DOM 结构与交互逻辑 |
| B6 | **克制程度** | 没有多余的装饰、动效、渐变 | 有为了「好看」而加的视觉噪音 |
| B7 | **一致性** | 与已定稿的其它屏共用同一套组件形态 | 每屏各写各的 |

**总分 35。建议门槛：≥ 26 分且 B1、B2 均 ≥ 4 分。**

B5 要诚实打分：这一项决定你要花几天还是两周。一个视觉上惊艳但需要重写 DOM 的变体，实际成本可能高于它带来的收益。

## D. 决策门槛（第 1 屏）

`popup-organize` 是试金石。看完 3 个变体后：

**继续投入完整流程**，当且仅当：至少 1 个变体在不引入白名单外颜色、且 360px 无横向溢出的前提下，**B1 + B2 合计 ≥ 9 分**。

**否则**：把 Stitch 降级为「灵感来源」（方案第五节路线 A），不进入代码移植，只从变体里挑 1–2 处局部改进手工实现。

这个门槛故意设得偏高。原因：移植一屏的成本是 2–4 天，如果参考稿在密度与层级上并不比现状强，那这几天的收益跑不赢回归风险。

## E. 移植前的最后一道检查

定稿后、动代码前，逐条确认：

- [ ] 选定方向已截图存档到 `docs/stitch/`（作为验收基线）
- [ ] 参考稿里用到的每个颜色，都能映射到 `tokens.css` 的语义变量；映射不上的，已确定要在色阶里新增哪个值
- [ ] 参考稿里用到的每个圆角/间距，都落在白名单五档/五档内
- [ ] 现有 `tests/ui-redesign.test.js` 的 12 条不变式（见方案第四节）不会因为这次改动变红
- [ ] 交互层（拖拽、FLIP 落位、乐观更新、焦点陷阱栈、快捷键注册表）确认**不改动**
- [ ] 中文文案沿用现有 HTML 里的字符串，不用参考稿的英文占位
- [ ] 已确认分页灰度顺序：`newtab` → `options` → `popup`
